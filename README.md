One line, under 200 characters: the excuse a hardware wallet gives for
refusing to sign a transaction at 3 AM. Built for the make.fun bounty
"The 3 AM Excuse": https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878

`main.py` (pure Python standard library) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
